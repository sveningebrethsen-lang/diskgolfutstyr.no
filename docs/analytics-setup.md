# Analytics-oppsett

Gjeldende status og oppskrift finnes i [analytics.md](analytics.md).

Cloudflare Web Analytics er installert lokalt på 158 HTML-sider per 6. september 2026 med eierens offisielle JS-snippet. Endringen er ikke publisert i denne fasen, og mottatt trafikk er ikke verifisert. Se analytics.md for kontrollene før og etter publisering. GA4 er ikke installert.

Den tidligere oppskriften er erstattet for å skille offentlig beacon-konfigurasjon fra private API-nøkler og for å beskrive målebegrensningene korrekt.
